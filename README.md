# Vendas IA

Relatório de vendas a partir do export real da plataforma (Hotmart, Kiwify, Eduzz, Monetizze, Ticto, Stripe ou qualquer planilha, .csv/.xlsx): mapeamento de colunas, normalização de status, faturamento bruto/líquido, reembolso, chargeback, conversão de Pix/boleto, mix por produto/origem/afiliado, série diária, mapa dia × hora, clientes multi-produto e comparação entre períodos — tudo calculado no navegador. A IA (BYOK OpenRouter) recebe só agregados e escreve a análise. Exporta PDF/HTML/PNG + CSV normalizado.

Site estático — o único backend são os webhooks n8n do gate. Ver DEPLOY.md.
